## ⚡ How to Easily Rename the Studio

If a new final brand name is selected later, you can update it across the entire website in **one single place**:

1. Open `index.html`.
2. Scroll to the `<script>` tag near the bottom.
3. Update the `BRAND_CONFIG` object:
   ```javascript
   const BRAND_CONFIG = {
       brandName: "YOUR STUDIO NAME",
       brandTagline: "Your Tagline Here",
       brandDomain: "yourdomain.studio",
       email: "hello@yourdomain.com",
       whatsapp: "+91 00000 00000",
       whatsappUrl: "https://wa.me/910000000000",
       location: "Remote Worldwide",
       year: "2026"
   };
   ```
4. Save the file. All headings, footers, metadata, contact buttons, and email links will update automatically.
