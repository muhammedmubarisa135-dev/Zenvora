## 🚀 Overview

Volcano Studios is a full-service digital and creative portfolio representing a modern duo of senior software architects and creative directors.

* **Websites First**: Custom Next.js/React web platforms, e-commerce, Supabase real-time databases, sub-second speeds, and 100/100 SEO health.
* **Creative Solutions & 360° Publicity**: Cinematic video editing, AI video making, commercial photography, brand identity systems, poster design, and high-converting Meta & Google ad campaigns.

## 🛠️ Tech Stack & Tools

* **Frontend**: HTML5, Modern JavaScript (ES6+), Tailwind CSS
* **Styling**: Pre-compiled pure CSS (`style.css`), Glassmorphism, Responsive Mobile-First Design
